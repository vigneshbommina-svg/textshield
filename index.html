    Formal definition: DFA 5-tuple

    M = (Q, Σ, δ, q₀, F)

    Q

    {q₀, q₁, …, q₃₁}, all 32 states.

    Σ

    {U, C, A, L, P}, the five feature symbols.

    δ

    δ(qₘ, x) = q₍ₘ OR b(x)₎.

    q₀

    Initial state, bit mask 00000.

    F

    States where C AND (U OR A OR L) are present. These states satisfy the demo's phishing-pattern rule.

    The bit string is displayed in P-L-A-C-U order. Each new feature sets its bit to 1; existing bits remain set.

    05 / PROJECT NOTES

    How TextShield works

    1. 1
      Read the message

      The user enters text into the analyzer.

    2. 2
      Match regular expressions

      Predefined rules detect the five feature types.

    3. 3
      Update the DFA state

      Bitwise OR combines all detected features into one of 32 states.

    4. 4
      Explain the output

      The accepting rule and extra classification rules produce the result and explanation.
